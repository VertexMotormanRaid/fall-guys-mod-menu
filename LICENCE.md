## 🧩 About

**Fall Guys Mod Menu** is a curated list of Fall Guys open-source tools:

- **Overlays** — on-screen helpers, layout notes, obstacle viewer, checkpoint switcher
- **Quality-of-Life Helpers** — costume catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Checkpoint Switcher — practice from any checkpoint
- Show Hitboxes — visualize obstacle hitboxes
- Replay Notes — record and review course runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### Wallhack
- Costume Catalog — browse costumes, colors, patterns, emotes
- Custom Skin Notes — organize player cosmetics
- Solid Trail — improved visual clarity

### Aimbot
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-course
- Jump Buffer Notes — chain complex maneuvers in the editor
